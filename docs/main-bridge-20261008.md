## 新增功能解析

| 来源 | 功能 | 行为及桥接接点 |
| --- | --- | --- |
| 本地 | 区域实体按需生成 | 未揭示区域只保留定义，不参与模拟或渲染；区域出口揭示目标区域后生成实体；撤销恢复揭示范围及运行时。保持 configuredMap 和活动 world 的区分。 |
| 本地 | 当前模型验收 | 模型依据当前 prefab visual，游玩模式使用模型，编辑使用标志；保留离线资源预扫描及浏览器模型验收。 |
| 本地 | 喷射方向高亮 | 仅显示当前方向的前方射程，上一轮射击范围不参与高亮；攻击历史仍保留。 |
| 本地 | 火焰鸟提示 | 活动火焰鸟生成提示追踪，玩家显示橙红光环；中心 9×9 警戒范围提示发怒；重启、撤销、退出游玩同步反馈。 |
| 远程 | 机制触发器 | 机制支持 walk/teleport 选择（远程当前要求非空列表）；检视器固定触发控件和权限规则。进入限制不可因取消事件订阅而失效。 |
| 远程 | 易碎倒计时 | 配置行动次数，action 广播减少剩余次数；破碎后不再显示或承载。需核对 breaking/broken 与动画的边界，避免帧率影响逻辑。 |
| 远程 | 音频 | 音乐、行走、折叠、开关、喷射、火焰鸟及结局声音；UI 静音与音量；构建嵌入音频。保持动作结算与声音播放的边界。 |

## 冲突处理规范

1. 逐文件分析双方改动，禁止整文件采用 ours/theirs 覆盖业务实现。
2. 玩家状态机、行动入口、广播、机制和提示生命周期只在 work/player.cjs；app.ts 负责装配与显示。
3. 新区域先生成实体，随后广播/机制执行只消费活动实体。验证隐藏实体不攻击、不计倒计时、不打开出口。
4. 合并火焰鸟 trigger 与音频时保留追踪提示和光环；警戒距离复用 firebird.cjs。不要为提示复制攻击规则。
5. 喷射高亮继续只读取当前方向；保留远程射击音效与触发过滤，不复原背面上一轮高亮。
6. 保留此前纸张连接、厚度、过渡比例、折叠碰撞、摄像机与模型资源预扫描。旧桥接文档的历史规则不能覆盖后续已实现约定。
7. 数据、权限、检视控件和导出字段同时桥接。显式已有地图配置不因 prefab 默认值变化被自动迁移。
8. outputs/index.html 与 game.html 是构建产物，不手工拼接；源码冲突处理完成后统一构建。
9. 文本冲突可按接口契约组合；两种互斥玩法或无法推断的生命周期必须列出案例并请用户决定，批准前不替用户选取。
10. 每个完整桥接问题包含回归测试。保存原始双方提交和测试，不能通过删测试解决冲突。
