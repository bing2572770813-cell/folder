# 四机制序章：反向走廊

这是一个 7×7 的教学关卡，目标是让玩家依次理解易碎、方向喷射、升降和折线开关。出口位于右下角；折线开关为 0 时，出口只能站上去，不能离开地图。

## 地图布局

坐标使用“行号 + 列字母”。`·` 是普通纸张，`S` 是易碎起点，`R` 是方向喷射，`L` 是升降方块，`X` 是折线开关，`E` 是出口，`#` 是虚空。

```text
       A  B  C  D  E  F  G
  1    #  #  ·  │  ·  #  #
  2    #  #  ·  │  ·  #  #
  3    S  ·  ·  │  ·  ·  ·
  4    ·  ·  R  →  L  ·  ·
  5    ·  ·  ·  │  ·  ·  ·
  6    #  #  ·  │  ·  #  #
  7    #  #  ·  │  X  E  #
```

- `S`：易碎纸张，玩家从 C3 起步，第一次成功离开后变为虚空。玩家必须先走向 B3，不能原地等待。
- `R`：C4 的方向喷射方块，初始朝东。每次有效行动后向当前方向射出三格，再反向。第一次经过时，玩家应利用 B3 → B4 的路线避开射线；之后看到它朝西，理解“下一次方向”。
- `L`：E4 的升降方块，最低高度 0.09，最高高度 0.75，单程 3 回合。它不控制通行，只展示玩家占据时下降、离开后继续往返。
- `X`：E7 的折线开关，初始状态 0，放在唯一的竖直折线上。玩家使用这条折线后切换为 1；地图中仍有 0 开关时，出口 E7 只允许站立，不允许进入下一关。
- `E`：F7 的出口。出口前保留一格普通纸张，给玩家明确的“开关已打开但还需要走一步”的反馈。

竖直折线位于 D1–D7。它把 C 区和 E 区连接起来，但不直接绕过方向喷射方块；开关本身位于 E7，必须通过一次折线操作才能切换。

## 预期解法

1. 从 C3 向 B3 移动，离开易碎起点；回头观察 S 已经变成虚空。
2. 沿 B3 → B4 → B5 → C5 移动，避开 C4 的喷射方块；每次成功行动都让玩家看到射线范围和方向反转。
3. 通过 C5/D5 的折线操作到达 E5 一侧。折线传送算同一回合，升降方块只推进一次。
4. 经过 E4 升降方块，先观察玩家占据时高度下降，离开后继续按回合数推进。
5. 使用 D7 的竖直折线到达 E7，触发折线开关从 0 变为 1。界面应显示绿色开启状态。
6. 走到 F7 出口。此时没有状态为 0 的开关，出口转换成功。

## 设计约束

- 方向喷射的三格射线会穿过普通障碍和虚空，因此玩家不能靠放置阻挡方块“拆掉”射线。
- 易碎起点没有第二张纸张承载，破碎后不能回到起点，避免玩家用撤销之外的方式重置路径。
- 升降方块不是计时器；玩家停留或打开面板不会推进高度。
- 开关状态由折线使用触发，普通行走不会切换；出口失败时玩家位置和开关状态保持不变。
- 关卡不依赖隐藏规则：射线范围、当前方向、开关状态、升降高度和易碎状态都在画面中可见。

## 验收清单

- [ ] 玩家首次成功离开 C3 后，S 变为虚空；撤销恢复。
- [ ] R 的方向在每个成功行动后反转，最近射线与下一次预览不重叠成同一种颜色。
- [ ] L 在玩家占据时只下降，3 次有效行动完成单程；空闲帧不变化。
- [ ] 折线使用一次只切换 X 一次；行走和失败传送不切换。
- [ ] X 为 0 时站在 E7 不会进入 F7；X 为 1 后可以进入出口。
- [ ] 保存、加载、重开和撤销不把运行时状态写进地图配置。
