# FOLD FIELD 编辑器

在项目根目录运行：

```powershell
npm --prefix work run build
npm --prefix work start
```

打开 http://127.0.0.1:4173 。修改服务代码后需要重启服务。`outputs/index.html` 是编辑器，`outputs/game.html` 是内置示范关的独立游戏。

## 交互

- 右键拖拽平移；滚轮缩放。左键点击和拖拽用于当前编辑工具，按住 Shift 也不会切换为平移。触屏双指平移和缩放，单指编辑。
- 框选工具：左键拖出矩形，复制后点击粘贴，再点击目标区域左上格。Esc 取消选区或粘贴。空格和完整方块属性一起复制；起点与出口标记不会复制。越界粘贴整次拒绝。
- 连续绘制可以一次撤销，重做可以恢复。大地图的历史数量按地图面积限制，避免无界占用内存。
- 方块工具的颜色、高度和实体类型同时用于改色工具与放置工具。高度范围为 0.01–16，仅改变外观高度；移动仍使用原有八向规则。
- 地图宽高范围为 3–128；列坐标从 A 延伸至 DX。空格为虚空，放置工具可以在虚空区域添加方块。
- 网格按钮控制已有方块表面的浅灰勾线；坐标、地形、折纸与出口、玩家四个显示图层独立控制。隐藏图层不会修改地图或规则，进入游玩时恢复显示。
- 点击方块放置折线，会在该完整直线上所有已有方块添加同方向标记，跳过空格。交点保留多个方向；游玩时重复点击交点切换折线方向。移除工具移除点击格所携带各方向的完整折线，保留其他方向。

## 实体方块 prefab

`assets/prefab/*.json` 每个文件封装一个实体。格式如下：

```json
{
  "version": 1,
  "id": "paper_ai",
  "name": "纸张方块",
  "tile": {
    "color": "white",
    "height": 0.09,
    "blocked": false,
    "folds": []
  }
}
```

颜色可用 `white/red/yellow/blue/green/purple/black`。折线方向可用 `h/v/d1/d2`，支持交叉。`blocked` 是实体通行属性，独立于其颜色；普通自定义方块仍按黑色阻挡的旧规则处理。

服务每次请求重新读取目录，编辑器每两秒刷新列表，支持新增、修改和移除 JSON；坏文件与重复 ID 会显示错误，不阻止其他实体加载。选择实体加载其默认颜色、高度和通行属性，随后可调整颜色和高度。已放置方块保存属性快照与 `prefabId`，修改 prefab 不会改写已放置的地图。

“保存为实体方块”将当前方块工具配置保存为新的 `_ai.json`，不会覆盖已有文件。AI 生成资源遵循 `assets/README.md` 的命名要求。

直接用文件方式打开 HTML 时，浏览器无法自动扫描磁盘文件夹，因此使用构建时内置的实体目录；保存按钮会下载 JSON。将文件放入 `assets/prefab` 后运行本地服务即可实时加载，或重新构建更新离线目录。独立游戏导出同时内置地图与实体目录，不依赖服务。

旧版单个 `fold` 地图兼容导入，新增方块保存 `height/blocked/folds/prefabId`。无效起点或出口可作为编辑草稿导入，但会禁止进入游玩与导出游戏。

## 检查

```powershell
npm --prefix work test
```

测试覆盖选区复制粘贴、整轴折线与交点、旧地图兼容、128 地图、prefab 校验与磁盘刷新、防止文件覆盖，以及独立 HTML 和示范关解法。
