# FOLD FIELD 编辑器

在项目根目录运行：

```powershell
npm --prefix work run build
npm --prefix work start
```

打开 http://127.0.0.1:4173 。修改服务代码后需要重启服务。`outputs/index.html` 是编辑器，`outputs/game.html` 是内置示范关的独立游戏。

## 交互

- 右键拖拽平移；滚轮缩放。左键点击和拖拽用于当前编辑工具，按住 Shift 也不会切换为平移。触屏双指平移和缩放，单指编辑。
- 框选工具：左键拖出矩形，复制后点击粘贴，再点击目标区域左上格。Esc 取消选区或粘贴。空格和完整方块属性一起复制；起点与出口标记不会复制。越界粘贴整次拒绝。
- 连续绘制可以一次撤销，重做可以恢复。大地图的历史数量按地图面积限制，避免无界占用内存。
- 方块工具先选择后端实体类型，再调整高度与该实体支持的颜色，用于应用属性与放置操作。高度范围为 0.01–16，仅改变外观高度；移动仍使用原有八向规则。
- 地图宽高范围为 3–128；列坐标从 A 延伸至 DX。空格为虚空，放置工具可以在虚空区域添加方块。
- 网格按钮控制已有方块表面的浅灰辅助勾线；实体自身的边缘样式独立保留，纸张实体使用 `#414140`。坐标、地形、折纸与出口、玩家四个显示图层独立控制。隐藏图层不会修改地图或规则，进入游玩时恢复显示。
- 折线逐格点击放置，支持已有方块与空格，不再拖拽铺线或自动铺满整条直线。同方向标记只沿该方向的两个邻格合并；不同方向独立成组，断开的标记独立成组。移除只影响点击格的标记，必要时拆分并重新计算。
- 合并折线端点位于首尾格的边界，限于地图边界；虚线长段为纸张边长的 1/3，与点交替，虚空也可显示。各方向每个折线格的距离贡献均为 0.5，横/纵折线作用半径 d = ceil(折线格数量 × 0.5)，斜向折线 d = floor(折线格数量 × 0.5)。玩家距离使用切比雪夫距离 `max(abs(行差), abs(列差))`：奇数格折线取到几何中心格的距离，偶数格折线取到中间两个格子的距离较大值，距离 ≤ d 时才可传送；原有目标通行和边界校验仍有效。单格横/纵线半径为 1、斜线为 0；三格横/纵线为 2、斜线为 1。编辑模式悬浮所在格时，视口左下角显示各方向半径。
- 空格标记保存为地图的 foldCells: [{r,c,type}]；实体上的独立 folds 仍保存，复制粘贴、撤销重做与尺寸裁剪都包含空格标记。删除实体保留其折线，放置实体把原空格标记转入实体属性。旧地图可读取，但短折线将按新范围规则计算。
- 示范关为适配有限范围，在左侧增加三列虚空并补齐原有三个方向的连续标记，原有唯一六步解仍成立。

## 实体方块 prefab

`assets/prefab/*.json` 每个文件封装一个实体。格式如下：

```json
{
  "version": 1,
  "id": "paper_ai",
  "name": "纸张方块",
  "tile": {
    "color": "white",
    "edgeColor": "#414140",
    "height": 0.09,
    "blocked": false,
    "folds": []
  }
}
```

`color` 是可选实体属性，可用 `white/red/yellow/blue/green/purple/black`；缺少它时前端隐藏颜色栏，渲染采用中性白色，也不会给实体补写颜色。`edgeColor` 是可选六位十六进制边缘颜色。折线方向可用 `h/v/d1/d2`，支持交叉。`blocked` 是实体通行属性，独立于其颜色；旧版没有显式通行属性的地图仍兼容黑色阻挡规则。

服务每次请求重新读取目录，编辑器每两秒刷新列表，支持新增、修改和移除 JSON；坏文件与重复 ID 会显示错误，不阻止其他实体加载。选择实体加载其默认颜色、高度和通行属性，随后可调整高度，有颜色属性时可以调整地图实例的颜色。已放置方块保存属性快照与 `prefabId`，修改 prefab 不会改写已放置的地图。

实体定义只能由后端程序写入，地图编辑器没有创建或保存实体的入口，HTTP 实体接口仅允许 GET。后端可运行 `node work/write-prefab.cjs <实体定义.json>` 校验并写入新实体，已有文件和 ID 不会覆盖。AI 生成资源遵循 `assets/README.md` 的 `_ai` 命名要求。地图保存的是实体实例属性快照，不会写入 prefab。

直接用文件方式打开 HTML 时，浏览器无法自动扫描磁盘文件夹，因此使用构建时内置的实体目录。将文件放入 `assets/prefab` 后运行本地服务即可实时加载，或重新构建更新离线目录。独立游戏导出同时内置地图与实体目录，不依赖服务。

旧版单个 `fold` 地图兼容导入，新增方块保存 `height/blocked/folds/prefabId`。无效起点或出口可作为编辑草稿导入，但会禁止进入游玩与导出游戏。


测试覆盖选区复制粘贴、逐格折线合并/拆分与交点、切比雪夫范围、点线交替、旧地图兼容、128 地图、prefab 校验与磁盘刷新、防止文件覆盖，以及独立 HTML 和示范关解法。

## 机制实体

合并 main 后支持篝火、冰河、火焰、喷发、钥匙与终点实体，属性保存为 tile.terrain 和 tile.terrainConfig。实时目录服务的解析模块修改后须重启本地服务。

保留 editor 的折线规则：阻挡实体可携带折线，虚空也可保存折线。阻挡实体本身仍不可行走或成为传送目标。机制进入限制与现有折线范围校验同时生效。拾取钥匙后到达终点可通关，重启与游玩撤销包含机制状态。

## 实体占格、玩家与区域

实体 prefab 增加 `size: {width: 2, height: 3}` 与按行排列的 `occupied: [true, false, true, true, true, true]`。大纸块以此掩码占用五格，空洞不覆盖已有方格。放置允许覆盖已有实体，但任意实际占用格被隐藏或越界时整次拒绝。多格实例保存唯一身份；复制粘贴生成新的身份，删除按实例处理。局部覆盖允许剩余占格保留为原实例。

实体类型用可展开的预览图标网格选择，悬停显示名称；放置前按实际占格掩码显示轮廓，越界或覆盖隐藏区域时标红。入口、出口显示箭头标记。Player Token prefab 可放置及改色。游玩模式自动生成带眼睛的正十二面体 player，只有它接受玩家操控。玩家状态、移动、折纸传送、区域切换、动画、重启、撤销及朝向逻辑集中在 `player.cjs`。

选区支持 Shift + 左键拖拽叠加，点击虚空取消。输入唯一名称后设置区域标签；同一个 `regionTag` 的方格属于同一区域，与空间连通性无关。默认旧地图迁入“默认区域”。显示图层中可按区域隐藏；隐藏实体不能被放置、涂改、删除、粘贴或改标签覆盖。

方块工具的“方块标签”设置玩家起点、区域入口和区域出口；出口指定目标区域名称。起点全图唯一，入口每区域唯一，起点与入口不能共存于同一区域。游玩初始只显示起点所在区域，进入出口后传送至目标入口并累计显示已到达区域。撤销恢复此前显示集合，重启只显示初始区域。地图工具不再提供设置起点/出口按钮；旧地图出口仍兼容通关。没有通关目标的地图也可游玩测试。

网格覆盖地图内虚空；网格关闭不隐藏纸张实体自身的 `#414140` 边缘。

## 地图名称

编辑器顶部中央的地图名称可直接插入光标修改，自动保存到地图 `name`。导入、新建、撤销同步名称；右侧视图显示“名称 / 编辑”或“名称 / 游玩编辑”。导出地图默认文件名为 `name.json`；非法文件名字符替换为下划线，空名称回退“未命名关卡”。连续一次名称输入合并为一条编辑历史。
