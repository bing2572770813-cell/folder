# 编辑器模块开发约束

- 本目录实现编辑器数据操作，不访问 DOM、localStorage、Three.js 或玩家状态机。
- 所有写入先完成边界、隐藏保护与唯一标签校验，失败不得留下部分修改。
- 保留稀疏掩码和独立虚空折线；不可把包围盒当作全部实际选中格。
- 新增可序列化字段须覆盖剪贴板、历史与地图往返，非序列化调试状态不得固化为配置。
- 修改选区或粘贴需运行 test-editor-model.mjs；遵循根 AGENTS.md 的提交和 player.cjs 约束。
- 多格实体实际选区必须包含同实例全部占用格；直接格与联动格仅用于蓝红勾线及独立方格属性的区分。区域标签属于固定地图格，区域数据操作只修改传入格；同实例可以跨多个区域，移动和放置保留目的格区域。
